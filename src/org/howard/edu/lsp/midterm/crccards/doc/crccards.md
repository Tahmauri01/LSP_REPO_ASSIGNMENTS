Library collaborates with Book because its CRC responsibilities require it to store, find, and call methods on Book objects. Book lists no collaborators because its responsibilities are only its own data, so it never needs to know which Library holds it. This one-way dependency keeps Book simple/reusable. Library has the three-book borrowing limit because the limit is a rule about the whole collection, and only Library can see how many of its books are currently borrowed, which matches its CRC responsibility to “enforce borrowing limit.” A single Book only knows its own state, so it cannot enforce a limit across many books.
